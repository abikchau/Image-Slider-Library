# Image Slider Library

## Project Overview
Image Slider Library is a responsive image slider built using HTML, CSS, and JavaScript. It allows users to browse images using navigation arrows and clickable dots.

## Features
- Next and Previous navigation buttons
- Infinite looping between images
- Smooth sliding animations
- Clickable navigation dots
- Current slide counter
- Responsive design for desktop and mobile
- Keyboard navigation using arrow keys

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` — Provides the structure of the image slider.
- `style.css` — Controls the layout, appearance, and responsive design.
- `slider.js` — Implements navigation, animation, and infinite looping.
- `assets/` — Stores local image files.
- `screenshots/` — Contains screenshots of the project.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use the navigation arrows or dots to browse the images.
